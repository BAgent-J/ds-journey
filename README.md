# ds-journey

西南大学数学系 → 大厂数据/算法实习的**学习账本**。从 2026-11-18 开始，59 周。

## 目标

- 2027 年 9 月：投出第一份大厂日常实习（腾讯等）
- 方向：数据分析为主，搜广推算法并行
- 每周投入：10-14 小时

## 目录

| 目录 | 放什么 |
|---|---|
| `week01/` ~ `weekNN/` | 每周的任务清单、notebook、当周作业 |
| `notes/` | 长期沉淀：SQL 模板、刷题笔记、八股卡片 |
| `projects/` | 三个正式项目（EDA / 机器学习 / 推荐系统） |
| `data/` | 练习用数据（大文件不进仓库，见 .gitignore） |
| `progress.md` | 59 周进度勾选表 |

## 怎么用

1. 每周日晚上打开 `progress.md`，看下一周那一行
2. 进对应的 `weekNN/README.md`，把任务抄进日历
3. 每天学完，在 README 里的任务后面打勾，随手记一行「今天卡在哪」
4. 周日填 `progress.md` 的状态

**规则：只允许提前，不允许跳过。**跳过的任务写进下周 README 的「补做」里；连续两周补不上，直接删掉这个任务，不要留着欠账。
